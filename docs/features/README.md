# Feature Documentation Directory

This directory contains individual technical specifications, API contracts, usage guides, and data flows for every feature built across the course modules.

## Document Naming Convention
Feature documents are named sequentially by module:
- `01_healthcare_mcp_server.md` (Module 2)
- `02_single_agent_summarizer.md` (Module 3)
- `03_multi_agent_orchestration.md` (Module 4)
- `04_dual_llm_phi_router.md` (Module 5)
- `05_clinical_rules_and_hitl.md` (Module 6)
- `06_production_hardening_and_ui.md` (Module 7)
- `07_system_error_handling_and_output_normalization.md` (Production Incident Interception)
- `08_visual_transaction_journey_and_audit_explorer.md` (Visual Audit Log & Pipeline Explorer)

## Standard Feature Document Template
Each feature document follows this format:
1. **Feature Overview & Purpose**
2. **Architecture & Data Flow**
3. **API Contracts / Interface Definitions**
4. **Execution & Demonstration Instructions**
5. **Validation Results**
